# AI in HR: Interactive Tour for Lodha Developers Limited

A single, self-contained HTML page (`index.html`) prepared by Impeccker Consulting. It has no external dependencies: no CDN, fonts, images or build step. Logos and the favicon are embedded, so it also works offline.

## Host on GitHub Pages
1. Create a repository and add `index.html` (and this README) to the root of the default branch.
2. Go to **Settings > Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
3. The page is served at `https://<user>.github.io/<repo>/` within a minute or two.

A private repository needs a GitHub plan that supports Pages for private repos. For a client-specific page, consider sharing the file directly instead, because a public Pages site is visible to anyone with the link.
